# Cosmic Developer Portfolio

A responsive, space-themed portfolio website for Andrew Bhone.

## Run locally
Open `index.html` in a browser.

## Publish for free with GitHub Pages
1. Create a GitHub repository named `Portfolio` (or any name you prefer).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then Save.
6. After deployment, your site will appear at `https://YOUR-USERNAME.github.io/Portfolio/`.

Replace the generic GitHub button URL with your own profile URL before publishing.
